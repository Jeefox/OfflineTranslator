## Limitations

- Each backend runs in a separate process; peak RSS (ru_maxrss)
  covers the whole process (interpreter + imports + model) — it is
  not attributed to the model alone.
- Marian first run may download models into the existing model
  cache (existing project mechanism); load time is reported
  separately from translation latency.
- Hy-MT2 runs at POC settings (temperature=0.0, n_ctx=4096,
  CPU only) — current production parameters, not tuned for the
  benchmark.
- numbers_preserved compares digit runs; numbers translated into
  words count as a structural fail (a fact, not a quality score).
- The current pipeline joins sentence units with spaces, so
  lines_preserved may legitimately fail for line-based inputs —
  a property of the pipeline, reported as data.
- This report contains data only; it does not rank or pick a
  winner — interpretation is left to the developer.
