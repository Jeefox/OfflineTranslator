# Changelog

## 0.1.0 — первый публичный релиз (28.09.2026)

Первый публичный релиз офлайн-переводчика EN↔RU.

### Что есть в этой версии

- **Единый translation-pipeline для разных бэкендов**: словарь (точное совпадение) → разбиение на логические юниты (предложения/абзацы) → инкрементальный кэш → бэкенд → сборка результата. Новый бэкенд добавляется в `backends/` без изменений общего сервиса и GUI.
- **Marian-бэкенд** (`marian`): две независимые модели Helsinki-NLP opus-mt — EN→RU и RU→EN; CPU/CUDA; token-aware разбиение длинных предложений (лимит входа 480 токенов), beam search; автоматическое скачивание при первом запуске в постоянный пользовательский кэш.
- **GGUF-бэкенд** (`llama_cpp`): `tencent/Hy-MT2-1.8B` через `llama-cpp-python` (только CPU, локальный `.gguf`-файл, скачивания нет).
- **Реестр моделей и manager** (`model_registry.py`): модели `marian-en-ru`, `marian-ru-en`, `hy-mt2-1.8b`; проверка локальной доступности без загрузки моделей и без сети.
- **Выбор модели в интерфейсе**: «Настройки» → «Модель» — доступность и совместимость с направлением, применение без перезапуска, активная модель видна в статусе; direction-aware выбор, включая смену местами полей.
- **Выбор направления**: выпадающий список «EN → RU» / «RU → EN» и кнопка «Сменить местами».
- **Streaming-перевод**: результат появляется по предложениям, прогресс текущего юнита («Перевод… (k/n)»).
- **Sentence-level highlighting**: одна активная пара «предложение ↔ перевод», hover/клик в обоих полях.
- **Синхронная прокрутка** полей ввода и перевода (двусторонняя, включая Linux).
- **Инкрементальный кэш перевода**: повторный перевод изменённого текста отправляет в модель только изменённые/новые юниты (ключ: модель + направление + текст юнита; в памяти, очищается при перезапуске).
- **Локальный словарь терминов**: точное совпадение, двунаправленный, политика 1:1, приоритет над моделью и кэшем.
- **Настройки и автоперевод**: направление, модель, тема, автоперевод после остановки набора (debounce), лимит длины, фильтр кириллицы (автоопределение направления), глобальный хоткей — в `settings.json`, применяются без перезапуска.
- **Горячие клавиши**: в окне (`Ctrl+Enter`, `Ctrl+L`, `Ctrl+,`) и опциональный глобальный хоткей (по умолчанию `Ctrl+Alt+T` — текст из выделения в любой программе попадает в приложение и переводится).
- **UI/UX**: тёмная/светлая схема, перенос строк, sanitized-сообщения об ошибках без внутренних идентификаторов, кнопка «Перевести» отключена на время загрузки модели, заметки о фолбэке моделей.
- **Benchmark-инфраструктура**: воспроизводимое сравнение Marian и Hy-MT2 GGUF (latency avg/median/p95, память, структурные свойства, детерминизм, streaming) на фиксированном датасете — `benchmarks/`.
- **Тесты**: standalone-сьюты в `tests/` (реестр моделей, бэкенды, пайплайн, streaming, кэш, настройки, UI/UX) — без реальных моделей, GPU и интернета.

### Ограничения версии

- только направление EN↔RU (реестр подготовлен к добавлению новых моделей/направлений);
- GGUF — только CPU и одна фиксированная модель (Hy-MT2 1.8B, POC-параметры);
- кэш перевода — только в памяти;
- глобальный хоткей — опциональный (нужен `pynput`; Linux — X11, Windows).
