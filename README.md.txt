# Офлайн Переводчик (EN → RU)

Локальный переводчик с английского на русский с использованием нейросети MarianMT.

## Возможности
- Перевод слов, фраз и предложений
- Работа без интернета (после первой загрузки модели)
- Технический словарь
- Графический интерфейс (CustomTkinter)
- Сборка в .exe файл
