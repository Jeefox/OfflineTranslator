# Офлайн Переводчик EN ↔ RU

Приложение для перевода между английским и русским языками, работающее полностью офлайн.

## Возможности

### Приоритет 1 (Реализовано)
- ✅ **Двусторонний перевод** — поддержка EN→RU и RU→EN
- ✅ **Выбор направления** — выпадающий список и кнопка смены полей местами
- ✅ **Редактируемый словарь** — вкладка "Словарь" с таблицей слов
  - Добавление, редактирование, удаление слов
  - Поиск/фильтр по словам
  - Импорт/экспорт в JSON
  - Сохранение изменений в реальном времени
- ✅ **История переводов** — вкладка "История" на базе SQLite
  - Хранение последних 50 переводов
  - Клик по записи — подстановка в поле ввода
  - Удаление записей и очистка истории
  - Экспорт в CSV

### Приоритет 2 (Частично реализовано)
- ✅ **Горячие клавиши**:
  - `Ctrl+Enter` — перевести
  - `Ctrl+C` — копировать перевод
  - `Ctrl+L` — очистить поля
  - `Escape` — закрыть диалоговые окна
- ⏳ **Перевод файлов** — планируется
- ✅ **Статистика и UX**:
  - Счётчик символов и слов в реальном времени
  - Время последнего перевода
  - Индикатор статуса модели
  - Кнопка смены полей местами (swap)

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

**Примечание:** При первом запуске приложение загрузит модели перевода (2-5 минут). Модели сохраняются в кэш и при последующих запусках загружаются быстрее.

## Структура проекта

```
├── main.py              # GUI приложение (CustomTkinter)
├── translator.py        # Класс OfflineTranslator с моделями MarianMT
├── dictionary_manager.py # Менеджер словаря (добавление, редактирование, поиск)
├── history.py           # Менеджер истории переводов (SQLite)
├── dictionary.json      # Пользовательский словарь терминов
├── history.db           # База данных истории переводов (создаётся автоматически)
├── requirements.txt     # Зависимости Python
└── README.md           # Документация
```

## Зависимости

- `customtkinter` — современный GUI фреймворк
- `transformers` — библиотека для работы с нейросетями
- `torch` — фреймворк глубокого обучения
- `sentencepiece` — токенизатор
- `sacremoses` — предобработка текста

## Модели перевода

Используются предобученные модели от Helsinki-NLP:
- `Helsinki-NLP/opus-mt-en-ru` — английский → русский
- `Helsinki-NLP/opus-mt-ru-en` — русский → английский

Модели загружаются из HuggingFace Hub и кэшируются локально.

## Формат словаря

Словарь хранится в `dictionary.json`:

```json
{
    "workspace": "рабочее пространство",
    "repository": "репозиторий",
    "рабочее пространство": "workspace",
    "репозиторий": "repository"
}
```
